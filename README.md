# きょう（ひび手帳の「今日」だけ版）

ひび手帳のタイムラインのうち、**今日だけ**を Structured 風に表示するアプリです。
月表示・日記・ふりかえりは開きません。
色はひび手帳のテーマカラーのブルー（#4F8ED6）が基調で、アイコンは地平線からのぼる太陽です（ライト／ダークはひび手帳の設定に合わせます）。予定の追加・変更・完了チェックはひび手帳で行います。

## しくみ

- ひび手帳が Google ドライブ（アプリ専用の場所）に自動保存している `hibi.json` を**読むだけ**です。こちらからは何も書き込みません。
- ログインはひび手帳と同じく、乗換案内の Worker（`/hibi-auth/`）を通します。URL は設定で変えられます（はじめは `https://norikae.gohanoishi.workers.dev`）。
- 同じ Safari でひび手帳が Google にログイン済みなら、そのログインをそのまま使います。ログインしていなくても、同じ Safari にひび手帳のデータがあればそれを表示します。
- 読み込んだ予定（日記や写真は除く）は端末に残すので、オフラインでも前回の内容を表示します。開くたび・画面に戻るたびにドライブの更新を確かめます。

## 表示するもの

- 今日の時間の決まった予定（繰り返し、「この回だけ休み」、大学の授業・補講を含む。休講の回は出さない）。「カレンダーだけ」の予定と日をまたぐ予定は出しません（ひび手帳のタイムラインと同じ）
- 前の日から続く夜勤などの予定
- 色つきのカプセル（長さに応じた高さ）を、予定の色から次の予定の色へのグラデーションの点線でつなぐ。空き時間、現在時刻のライン、いま進行中の予定の進み具合
- のりかえで追加した経路：乗る電車の路線をタイムラインに出し、タップで駅・発着時刻・番線・途中の駅・運賃を表示
- 終日の予定、祝日、学期の休み・振替授業日、今日まで（と期限切れ）のやること・課題
- 予定をタップすると、時間・繰り返し・行き先・メモ・持ち物（準備の状態）を表示

## iPhone で使う

1. このリポジトリの **Settings → Pages** で `main` / `(root)` を公開
2. `https://<ユーザー名>.github.io/hibi2/` を Safari で開き、「ホーム画面に追加」
3. 「Googleでログイン」で、ひび手帳と同じアカウントを選ぶ

> 乗換案内の Worker が、ログイン後の戻り先として `…/hibi2/` を受け付ける必要があります。ログイン後にエラーになる場合は、Worker の戻り先の許可に `/hibi2/` を追加してください。
